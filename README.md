# astrbot_plugin_lingqian

六十甲子灵签。抽一支，出一张签条图，附签诗和一句白话。

## 用法

```
/灵签 要不要换工作
/灵签 统计
/灵签 群统计
/灵签 26
```

别名：`/抽签`、`/求签`。问题可以不给，也可以只说半句。
`统计` 会告诉你抽过几次、碰到几支不同的签、各等级各几支、最近一支是什么。
`群统计` 看整个群：一共抽了几次、几个人抽过、谁抽得最多。
写个签号（`/灵签 26`、`第26` 都行）可以查那一支的全文，不消耗冷却。

## 签条

竖排四句签诗，从右往左读；上面是签号和干支，右下角盖朱印，下面是卦头故事，
最后一行是分项：功名、财禄、婚姻、疾病、出行各一句。读起来是一张签，不是一张西式牌。

抽之前会先回一句「摇了三下，一支跳出来」，停两秒再出签条。不想要这一步，把
`shake_enabled` 关掉。

## 内容

六十支签文取自公有领域的《天上聖母六十甲子籤》，签诗、干支、卦头故事都是原文。
吉凶等级、白话解和分项是另写的，写在 `data.json` 里，可以自己改。

等级分六档：上上、上吉、中吉、中平、中下、下下。这一版是按签诗语气的判断，
不是传世签谱上标注的定论；要严格的话得找有原注的版本核对。

## 配置

| 项 | 默认 | 说明 |
|---|---|---|
| `image_enabled` | true | 发签条图，关掉只回文字 |
| `image_width` | 760 | 签条图宽度，560~1200 |
| `cooldown_seconds` | 60 | 两次抽签之间的冷却，0 表示不限 |
| `shake_enabled` | true | 抽之前先摇一句 |
| `shake_delay` | 2 | 摇完等几秒再出图 |

## 去重

同一个人最近抽过的 12 支不会再出现。也就是说抽满 12 次之后，就会开始碰上抽过的签，
这跟庙里摇签是一个道理：签筒摇久了总会重复。记录在 `history.json`，一次抽签算一条。
