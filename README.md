# astrbot_plugin_lingqian

六十甲子灵签。抽一支，出一张签条图，附一句解语和分项。

## 用法

```
/灵签 要不要换工作      抽一支，出签条
/灵签 26                查第 26 支的全文，不消耗冷却
/灵签 今候              今天落在七十二候的哪一候
/灵签 统计              自己抽过几次、几支不同的签、等级分布
/灵签 群统计            本群一共抽了几次、几个人、谁抽得多
/灵签 订阅              这个群每天收一支
/灵签 退订              不再收
```

别名是 `/抽签`、`/求签`。问题可以不给，也可以只说半句。

## 抽一支的过程

```
摇了三下，一支跳出来。        ← 先回一句，停两秒

[签条图]                      ← 竖排签诗、签号干支、朱印、卦头故事、分项

第 12 签 · 乙亥第十二（中吉）
江上的浪头一层层落下去，现在可以开船；会有人替你搭把手，麻烦能脱开身

功名转机，财禄渐稳，婚姻有人牵，疾病脱险，出行宜行
```

那句解语是模型写的，它同时拿到签诗、白话、分项、卦头故事和当前时令，
对着你问的事说两三句。模型没配、超时或者报错，就退回规则生成的答案，不会不回话。

问得笼统（「今天运势」）会多一句提醒，让它往具体处说；问得具体（「要不要跳槽」）
就直接答那件事。签里没有的时间、数字、人名不许编，发出去之前还会再筛一道。
签文里没写「中午」的，回复里出现「中午」会被换成「这会儿」。

## 签条

竖排四句签诗，从右往左读；上面是签号和干支，右下角盖朱印，下面是卦头故事，
最后一行是分项，功名、财禄、婚姻、疾病、出行各一句。

纸是米黄的，带低频色斑和细颗粒，朱红双框，字用楷体。抽之前那句「摇了三下」
和出图之间隔两秒，`shake_enabled` 关掉就没这一步。

## 内容

签诗、干支、卦头故事取自公有领域的《天上聖母六十甲子籤》，是原文。

另外三样是后写的，写在 `data.json` 里，可以自己改。

吉凶等级分六档，上上、上吉、中吉、中平、中下、下下。这是按签诗语气的判断，
不是传世签谱上标注的定论，要严格的话得找有原注的版本核对。

白话解每支一句，贴着签诗的意象写，不留句号。

分项也是另加的。传统六甲子签只有签诗与卦头故事，没有这五项。加它是为了让解签
能落到具体事上，不算古籍原文。

## 七十二候

```
/灵签 今候

第 55 候 · 立冬一候「水始冰」
水面开始结冰
立冬已经 0 天，还有 14 天到小雪
（七十二候按黄河流域记，南边走的是另一套冷暖）
```

节气按太阳视黄经算，交界那天可能差一天。抽签和推送时这个候会一并交给模型，
让它把签放进眼下的时令里说。

## 每日一签

群里发 `/灵签 订阅` 就订上，默认早上八点推一支。改时间用 `daily_push_times`，
24 小时制，可以填多个。

推的内容和手动抽差不多，只是没人在问问题，所以固定按「今天是 11 月 8 日，
今天该留意什么」去问模型；解不出来就退回签诗加白话。

按日期取签，同一天推到各处都是同一支，六十天一轮。订阅表在 `daily_subs.json`，
也可以直接在 `daily_push_targets` 里写死会话。

重载插件后要先在群里说一句话，定时推送才会真正启动。插件加载时还没有事件循环。

## 配置

| 项 | 默认 | 说明 |
|---|---|---|
| `image_enabled` | true | 发签条图，关掉只回文字 |
| `image_width` | 760 | 签条图宽度，560~1200 |
| `cooldown_seconds` | 60 | 两次抽签之间的冷却，0 表示不限 |
| `shake_enabled` | true | 抽之前先摇一句 |
| `shake_delay` | 2 | 摇完等几秒再出图 |
| `llm_enabled` | true | 让模型对着问题解签 |
| `llm_max_chars` | 80 | 解语最长字数，超了按标点截 |
| `llm_timeout_seconds` | 20 | 等模型的时间，超时用规则答案 |
| `daily_push_enabled` | false | 定时推送总开关 |
| `daily_push_times` | [] | 推送时刻，如 `["08:00"]`，空着用默认八点 |
| `daily_push_targets` | [] | 直接写死的会话，一般用订阅就行 |

## 去重

同一个人最近抽过的 12 支不会再出现。抽满 12 次之后就会开始碰上抽过的签，
跟庙里摇签一个道理，签筒摇久了总会重复。记录在 `history.json`，
一次抽签算一条，还能算次数和最近一支。
